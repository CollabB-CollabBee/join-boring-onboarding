## 03. Automatic Résumé Evaluation (ATS) — What You Must Know

Most companies use an ATS (Applicant Tracking System) to filter résumés before a human sees them.  
If your résumé is not optimized for ATS, it may be rejected automatically.

This is not about “gaming the system”.  
It is about making your skills readable by machines and humans.

### What ATS Looks For
- clear section titles (Experience, Skills, Education)
- consistent formatting
- keywords that match the job description
- simple, readable structure
- no images, tables, or multi‑column layouts
- standard fonts (Arial, Roboto, Calibri)

### What ATS Cannot Read
- icons
- fancy templates
- text inside images
- multi‑column layouts
- unusual symbols (● ■ ★)
- PDFs exported incorrectly

### Required Format for This Project
- single‑column layout
- simple headings
- bullet points only
- no icons or graphics
- export as PDF (text‑selectable)
