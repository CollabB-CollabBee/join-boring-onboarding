# **2 — Resume Rewrite**

Your résumé must reflect your real skills, not your aspirations.  
 This stage helps you create a clean, honest, junior‑appropriate résumé that aligns with your GitHub profile and your actual experience.

## **What you will learn**

* How to describe your skills without exaggeration  
* How to write truthful, junior‑level bullet points  
* How to replace inflated titles with accurate ones  
* How to structure a résumé for early employability  
* How to align your résumé with your GitHub profile

## **What you will do**

* Rewrite your résumé using the provided template  
* Remove inflated or misleading claims  
* Replace titles like “CEO” or “Founder” with realistic alternatives  
* Update your skills to match what you can demonstrate  
* Write clear, simple, honest experience descriptions

## **Checklist**

\[ \] Replaced inflated titles with accurate ones    
\[ \] Updated skills to match demonstrated ability    
\[ \] Removed claims that cannot be supported by GitHub    
\[ \] Rewrote experience bullets to reflect real work    
\[ \] Used the provided junior-friendly résumé template
