# **1 — GitHub Profile Cleanup**

Before contributing to any codebase, you must present yourself professionally.  
 Your GitHub profile is often the first thing collaborators, reviewers, and future employers will see.  
 This stage teaches you how to make your profile clear, honest, and employable.

## **What you will do**

* Remove empty or low‑value repositories  
* Archive school assignments or tutorial repos  
* Rename repositories for clarity  
* Pin 3–4 meaningful projects  
* Add a professional GitHub profile README  
* Remove inflated titles or misleading descriptions  
* Align your skills with what you can actually demonstrate

## **Why this matters**

A clean GitHub profile:

* increases your credibility  
* improves your résumé acceptance rate  
* shows that you understand professional presentation  
* helps reviewers understand your real skill level

This is not about perfection — it’s about honesty and clarity.

## **Tasks**

Complete the checklist below:

\[ \] Removed empty or single‑file repos    
\[ \] Archived tutorial or school assignment repos    
\[ \] Renamed repos to reflect real content    
\[ \] Added a professional GitHub profile README    
\[ \] Pinned 3–4 meaningful repos    
\[ \] Removed inflated titles (e.g., CEO, Founder)    
\[ \] Updated skills to match demonstrated ability  

## **Submission**

Open a PR in the onboarding repo with:

* A screenshot of your cleaned GitHub profile  
* A short reflection (5–10 sentences):  
   *“What did I remove, what did I keep, and why?”*
