# **3 — Clean Code Starter Assignment**

This is your first technical task.  
 It is not about building features — it is about demonstrating your ability to write **clean, readable, maintainable code**.

You will refactor a small, intentionally messy codebase.  
 This allows us to understand your coding habits and your ability to follow standards.

## **What you will learn**

* Naming conventions  
* Folder structure discipline  
* Readability and clarity  
* Incremental commits  
* How to explain your decisions  
* How to submit a professional pull request

## **Your task**

* Read the messy starter code  
* Refactor it into clean, maintainable code  
* Follow the coding standards from `0_READ_FIRST`  
* Commit in small, logical steps  
* Write a clear PR description explaining your changes

## **Checklist**

\[ \] Improved naming and structure    
\[ \] Removed unnecessary complexity    
\[ \] Added comments only where needed    
\[ \] Followed project coding standards    
\[ \] Used clear, incremental commits    
\[ \] Wrote a professional PR description  

## **Submission**

Open a PR with:

* Your refactored code  
* A commit history showing incremental thinking  
* A short explanation of your decisions
